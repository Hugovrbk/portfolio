À propos

Je suis Verbeek Hugo, développeur web. J’aime transformer une idée en application que l’on peut vraiment utiliser : une carte de clips, un éditeur de cartes de rang, une boutique de collection, un calendrier d’actions étudiantes, mais aussi une boutique musicale, la vitrine d’un restaurant, un défi à vélo et le site d’un club de football.

Mes projets combinent HTML, CSS et JavaScript côté navigateur, et PHP avec MySQL côté serveur. Pour ce portfolio, je les ai adaptés en sites statiques : ils s’ouvrent sans installation, avec leur design et leurs contenus d’origine.

Front-end
HTML, CSS, JavaScript, Canvas, responsive, animations au défilement
Back-end (projets d’origine)
PHP, MySQL, comptes utilisateurs, administration, paiement Mollie, API externes
Cartes et API
Leaflet, MapLibre GL, globe.gl, OSRM, API Twitch
Outils
Git, Vercel, Supabase
