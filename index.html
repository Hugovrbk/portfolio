À propos

Je suis Prénom Nom, développeur web. J’aime transformer une idée en site que l’on peut vraiment utiliser : le site d’un club de football, une boutique de cadeaux, la vitrine d’un restaurant, une carte pour suivre un défi à vélo.

Mes projets combinent HTML, CSS et JavaScript côté navigateur, et PHP avec MySQL côté serveur. Pour ce portfolio, je les ai adaptés en sites statiques : ils s’ouvrent sans installation, avec leur design et leurs contenus d’origine.

Front-end
HTML, CSS, JavaScript, responsive, animations au défilement
Back-end (projets d’origine)
PHP, MySQL, comptes utilisateurs, administration, paiement Mollie
Cartes et API
Leaflet, OSRM, API Twitch
Outils
Git, Vercel, Supabase
